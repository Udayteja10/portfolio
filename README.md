## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Udayteja10/portfolio.git
```

Go to the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
